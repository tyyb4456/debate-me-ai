## **ARCHITECTURE OVERVIEW**

### **Technology Stack**
- **Backend Framework**: FastAPI (async support, automatic docs)
- **Workflow Engine**: LangGraph (already implemented in `graph_builder.py`)
- **Database**: PostgreSQL (relational data for users, debates, history)
- **Real-time Communication**: **Server-Sent Events (SSE)** - simpler than WebSocket, perfect for one-way streaming
- **ORM**: SQLAlchemy
- **Authentication**: JWT tokens (optional for MVP)
- **Deployment**: Docker + Docker Compose

## **1. DATABASE SCHEMA DESIGN**

### **Tables Needed:**

#### **1.1 Users Table**
```sql
CREATE TABLE users (
    user_id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    username VARCHAR(255) UNIQUE,
    email VARCHAR(255) UNIQUE,
    password_hash VARCHAR(255),  -- If implementing auth
    current_skill_level FLOAT DEFAULT 0.5,
    total_debates INTEGER DEFAULT 0,
    created_at TIMESTAMP DEFAULT NOW(),
    updated_at TIMESTAMP DEFAULT NOW()
);
```

**Purpose**: Store user accounts and aggregate stats

#### **1.2 Debate Sessions Table**
```sql
CREATE TABLE debate_sessions (
    session_id VARCHAR(255) PRIMARY KEY,
    user_id UUID REFERENCES users(user_id) ON DELETE CASCADE,
    topic TEXT NOT NULL,
    difficulty VARCHAR(20) CHECK (difficulty IN ('casual', 'standard', 'expert')),
    status VARCHAR(20) DEFAULT 'active' CHECK (status IN ('active', 'completed', 'abandoned')),
    
    -- Timestamps
    started_at TIMESTAMP DEFAULT NOW(),
    ended_at TIMESTAMP,
    
    -- Final metrics (populated when debate ends)
    total_turns INTEGER,
    avg_argument_strength FLOAT,
    fallacy_count INTEGER,
    overall_performance VARCHAR(20) CHECK (overall_performance IN ('poor', 'fair', 'good', 'excellent')),
    
    -- Full state snapshot (for replay/analysis)
    final_state JSONB,
    
    CONSTRAINT valid_end_time CHECK (ended_at IS NULL OR ended_at >= started_at)
);

CREATE INDEX idx_debate_user ON debate_sessions(user_id);
CREATE INDEX idx_debate_status ON debate_sessions(status);
CREATE INDEX idx_debate_started ON debate_sessions(started_at DESC);
```

**Purpose**: Store each debate session with metadata and final stats

#### **1.3 Turns Table**
```sql
CREATE TABLE turns (
    turn_id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    session_id VARCHAR(255) REFERENCES debate_sessions(session_id) ON DELETE CASCADE,
    turn_number INTEGER NOT NULL,
    
    -- Messages
    user_input TEXT NOT NULL,
    ai_response TEXT NOT NULL,
    
    -- Agent outputs (structured data)
    analyzer_output JSONB,
    research_output JSONB,
    socratic_output JSONB,
    advocate_output JSONB,
    
    -- Metadata
    user_skill_at_turn FLOAT,
    argument_strength FLOAT,
    timestamp TIMESTAMP DEFAULT NOW(),
    
    CONSTRAINT unique_turn_per_session UNIQUE(session_id, turn_number)
);

CREATE INDEX idx_turns_session ON turns(session_id);
CREATE INDEX idx_turns_timestamp ON turns(timestamp DESC);
```

**Purpose**: Store each turn (back-and-forth) in detail for analysis/replay

#### **1.4 Fallacies Table**
```sql
CREATE TABLE fallacies (
    fallacy_id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    session_id VARCHAR(255) REFERENCES debate_sessions(session_id) ON DELETE CASCADE,
    turn_id UUID REFERENCES turns(turn_id) ON DELETE CASCADE,
    
    fallacy_type VARCHAR(100) NOT NULL,
    text_span TEXT NOT NULL,
    explanation TEXT,
    severity VARCHAR(20) CHECK (severity IN ('minor', 'moderate', 'severe')),
    
    detected_at TIMESTAMP DEFAULT NOW()
);

CREATE INDEX idx_fallacies_session ON fallacies(session_id);
CREATE INDEX idx_fallacies_type ON fallacies(fallacy_type);
```

**Purpose**: Track fallacies for growth tracking and analytics

#### **1.5 User Achievements Table**
```sql
CREATE TABLE achievements (
    achievement_id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    user_id UUID REFERENCES users(user_id) ON DELETE CASCADE,
    
    badge_name VARCHAR(100) NOT NULL,
    description TEXT,
    earned_at TIMESTAMP DEFAULT NOW(),
    debate_id VARCHAR(255) REFERENCES debate_sessions(session_id) ON DELETE SET NULL,
    
    CONSTRAINT unique_user_badge UNIQUE(user_id, badge_name)
);

CREATE INDEX idx_achievements_user ON achievements(user_id);
```

**Purpose**: Gamification - track earned badges

#### **1.6 User Statistics Table** (Optional - for quick access)

## **4. STREAMING STRATEGY: Server-Sent Events (SSE)**

### **Why SSE over WebSocket?**

✅ **Simpler** - One-way communication (server → client)  
✅ **Auto-reconnect** - Browser handles reconnection automatically  
✅ **HTTP/2 compatible** - Works with standard infrastructure  
✅ **Perfect for AI streaming** - We only need server to push tokens  

❌ WebSocket: Overkill for one-way streaming, requires connection management

### **Implementation Strategy**

#### **Backend (FastAPI SSE)**

```python
from fastapi import APIRouter
from sse_starlette.sse import EventSourceResponse
import asyncio

@router.get("/debate/stream/{session_id}")
async def stream_debate_response(
    session_id: str,
    user_input: str  # Query parameter
):
    """
    Stream AI response token-by-token using SSE
    """
    
    async def event_generator():
        """Generate SSE events"""
        
        # Prepare state
        state = prepare_debate_state(session_id, user_input)
        config = {"configurable": {"thread_id": session_id}}
        
        # Stream through LangGraph workflow
        async for chunk in debate_app.astream(state, config=config):
            # Send different event types
            
            if "moderator" in chunk:
                yield {
                    "event": "status",
                    "data": json.dumps({"agent": "moderator", "status": "routing"})
                }
            
            elif "analyzer" in chunk:
                yield {
                    "event": "status",
                    "data": json.dumps({"agent": "analyzer", "status": "analyzing"})
                }
            
            elif "ai_response" in chunk:
                # Stream the actual response
                response = chunk["ai_response"]
                for token in response.split():
                    yield {
                        "event": "token",
                        "data": token + " "
                    }
                    await asyncio.sleep(0.01)  # Simulate streaming
        
        # Send completion event
        yield {
            "event": "complete",
            "data": json.dumps({"debate_ended": state.get("debate_ended")})
        }
    
    return EventSourceResponse(event_generator())
```

#### **Frontend (React SSE Consumer)**

```javascript
const eventSource = new EventSource(
  `http://localhost:8000/api/debate/stream/${sessionId}?user_input=${encodeURIComponent(userInput)}`
);

eventSource.addEventListener('status', (e) => {
  const data = JSON.parse(e.data);
  console.log(`Agent ${data.agent} is ${data.status}`);
  // Show loading indicator: "Analyzing your argument..."
});

eventSource.addEventListener('token', (e) => {
  setAiResponse(prev => prev + e.data);  // Append token
});

eventSource.addEventListener('complete', (e) => {
  eventSource.close();
  const data = JSON.parse(e.data);
  if (data.debate_ended) {
    // Show growth feedback
  }
});

eventSource.onerror = () => {
  console.error('SSE connection lost');
  eventSource.close();
};
```

### **Advantages of This Approach**

1. **Real-time feedback**: "Analyzing..." → "Researching..." → "Generating response..."
2. **Progressive rendering**: Tokens appear as they're generated
3. **Better UX**: User sees AI "thinking" vs waiting for full response
4. **Fault-tolerant**: Browser auto-reconnects if connection drops

## **5. KEY IMPLEMENTATION DETAILS**

### **5.1 LangGraph Integration**

Your `graph_builder.py` already has the workflow. The API just needs to:

```python
# In debate_service.py

from app.debate_system.graph_builder import create_debate_workflow

# Initialize once at startup
debate_app = create_debate_workflow()

def process_user_message(session_id: str, user_input: str):
    """Process message through LangGraph"""
    
    # Load or create state
    state = load_debate_state(session_id) or initialize_debate(session_id)
    
    # Update with user input
    state['user_input'] = user_input
    state['routing_phase'] = 'initial'
    
    # Run through workflow
    config = {"configurable": {"thread_id": session_id}}
    result = debate_app.invoke(state, config=config)
    
    # Save to database
    save_turn_to_db(session_id, user_input, result)
    
    return result
```

### **5.2 State Persistence Strategy**

**Two-layer approach:**

1. **LangGraph Checkpointer** (in-memory during debate)
   - Fast access for active debates
   - Handles conversation flow
   
2. **PostgreSQL** (persistent storage)
   - Save each turn to `turns` table
   - Save final state to `debate_sessions.final_state` (JSONB)
   - Enables replay, analytics, history

```python
def save_turn_to_db(session_id, user_input, result):
    """Save turn to database"""
    
    turn = Turn(
        session_id=session_id,
        turn_number=result['turn_count'],
        user_input=user_input,
        ai_response=result['ai_response'],
        analyzer_output=result.get('analyzer_output'),
        research_output=result.get('research_output'),
        socratic_output=result.get('socratic_output'),
        advocate_output=result.get('advocate_output'),
        user_skill_at_turn=result['user_skill_estimate'],
        argument_strength=result.get('analyzer_output', {}).get('argument_strength', {}).get('overall_score')
    )
    db.add(turn)
    db.commit()
```

from fastapi import Depends, HTTPException
from fastapi.security import HTTPBearer
from jose import JWTError, jwt

security = HTTPBearer()

async def get_current_user(token: str = Depends(security)):
    """Verify JWT token and extract user"""
    try:
        payload = jwt.decode(token.credentials, SECRET_KEY, algorithms=["HS256"])
        user_id = payload.get("user_id")
        if not user_id:

## **10. CRITICAL IMPLEMENTATION NOTES**

### **For the LLM generating the code:**

1. **Use your existing `graph_builder.py`** - Don't recreate it. The API should just call:
   ```python
   from app.debate_system.graph_builder import create_debate_workflow
   debate_app = create_debate_workflow()
   ```

2. **Database operations should be ASYNC** if using async FastAPI:
   ```python
   from sqlalchemy.ext.asyncio import create_async_engine, AsyncSession
   ```

3. **SSE streaming requires `sse-starlette`**:
   ```python
   pip install sse-starlette
   ```

4. **LangGraph's `astream()` for async streaming**:
   ```python
   async for chunk in debate_app.astream(state, config=config):
       yield chunk
   ```

5. **Session IDs should be in config for checkpointer**:
   ```python
   config = {"configurable": {"thread_id": session_id}}
   ```

6. **Save turns to DB after each message** - Don't wait for debate to end

7. **Use JSONB for flexible data** (agent outputs, final state)

8. **Add database indexes** on frequently queried columns (user_id, session_id, timestamp)

9. **Separate concerns**: Routes → Services → Database. Don't put business logic in routes.

10. **Environment variables for all secrets** - Never hardcode API keys
